# 加钱，换路，推日子

白板上的"3月15日"被划掉了。

一笔斜线，划得干脆。旁边新写一个日子：3月25日。字是新的，墨迹未干，尾上缀着两个字——暂定。

划掉的日期还看得见。看得见的东西，最难当没看见。

会议室里静了一下。笔帽旋开，又旋上。白板旧了，擦了写，写了擦。有些日子在上面留过太多次，有些日子只来了一回，就再没改过。

一场会，定下三件事。

第一件，钱。预算三十万，涨到五十万。涨的理由，只有一句"不够用"。上季度的三十万泼出去，像水泼进沙里，听不见回响，连个水花也捞不回来。如今再加二十万，是沙太干，还是水泼错了地方？没人问。没人接话的会，定得最快。提议的人开口，支持的人点头，拍板的人落笔。

第二件，路。渠道从抖音挪到小红书。挪的理由，是"转化率更高"。数字藏在谁的报表里？没人问。拍板的人点了头，提议的人合上本子，本子上什么也没写。一条河的改道，在散会之前就定了。

第三件，日子。三月十五是原定的，写进过方案，印进过排期。如今推到三月二十五；又或许，月底。包装设计未定稿，纸盒还摊在设计师的稿纸上，改了又改。货在等纸，纸在等笔。日子跟着纸走，纸不动，货就动不了。

钱不够，加；路不通，换。唯有日子，加不了，也换不得。它得一天一天地过，纸得一笔一笔地画。画到哪一天，货才走到哪一天。等的人做不了主，画的人不知道有谁在等。

最轻的一件事，记在表格最后一行，铅笔写的：KOL名单，今天之内发出。

名单早已确定。确定的名单，一直没走到等它的人手里。它在谁的抽屉里睡过，在谁的收藏夹里沉过，在谁的一句"稍后发送"里等着。要等一场会，等一个人转达，等"今天之内"四个字压下来，它才动身。

原来最贵的不是钱，是消息。消息不走路，人就得等。名单不重，重的是它没走完的路。

散会了。

茶杯还温着，椅子还歪着，白板上的日子还没擦。门开了，又合上。所有人都等一个人明天的回复。

王芳去问设计。设计给一个答案，答案再走回这场会，这场会明天还要再开一遍。一场会没走完的路，明天接着走。

明天有多远？隔一个夜晚，隔一次转述，隔一支还没落下的笔。

风从窗缝进来，翻动桌上那张记录纸。纸角翘起，又落下。翘起时像要说什么，落下时又没说。

纸上写着：加钱，换路，推日子。
