# 大纲生成 

## 输入
- source.md(原始素材)
- analysis.md(素材分析结果)
- 用户补充的写作方向(可选)

## 输出要求
 
 生成三到五个差异化大纲方案，分别保存为独立文件。
 
 每个方案必须：
 - 有明确的切入角度(不能只是换标题)
 - 标注叙事策略（故事驱动 /  观点先行 / 对比论证 / 教程式）
 - 列出各部分标题和一两句内容概要
 - 标注预估字数
 
 至少有一个方案采用故事驱动策略。
 
 ## 输出文件
 
 保存到 analysis.md 所在的目录：
 - outline-a.md
 - outline-b.md
 - outline-c.md
 - outline-d.md(可选)
 - outline-e.md(可选)

已有同名文件时先备份再覆盖。

生成完毕后，列出方案摘要，等待用户选择。
