# 文章润色

## 输入

- 待润色的文章

## 润色流程

### 第一步： 诊断

站在目标读者的角度通读全文，列出问题清单：
- 哪里读不通
- 哪里太啰嗦
- 哪里逻辑断裂
- 哪里有AI 味儿

### 第二步： 修改

按问题清单逐项修改。 没出修改标注原因。

### 第三步： 终检

加载 writing-style 技能，检查是否符合既定的写作风格。不符合的地方，逐一修改。

## 输出

保存到待润色文章所在目录。
- 润色报告: polish-report.md (修改了什么，为什么修改)
- 润色后的文章: final.md

已有同名文件时先备份再覆盖。
